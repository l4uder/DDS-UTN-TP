# Justificaciones

Arquitectura cliente servidor
* Es la arquitectura mas simple que cubre todos nuestros casos de uso, los usuarios necesitan una interfaz grafica 
para acceder al sistema, y el procesamiento se encuentra centralizado en un servidor.

Servicios externos de mensajeria
* Hacemos uso de servicios externos porque satisfacen nuestros requerimientos, y es la forma mas simple para la 
adicion de nuevos servicios de mensajeria, y para el mantenimiento, ademas, la implementacion de la mensajeria es ajena al objetivo central del sistema

Lenguaje Java
* Decidimos usar el lenguaje Java porque es un lenguaje moderno y rapido, que permite el uso de programacion orientada a objetos,
haciendolo perfecto para modelar el dominio del sistema.
